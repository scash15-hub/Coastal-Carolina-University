This website is a college recruitment website for Coastal Carolina University. The goal of this project is to give students information about the university, including student life, sports, academic programs, admissions, alumni, and contact information.
I created this website using HTML, CSS, Bootstrap, and JavaScript. The website is designed to be easy to navigate and responsive on different screen sizes.

Pages

The website includes the following pages:

- **Home** - Introduces Coastal Carolina University and includes school statistics, navigation cards, and a map.
- **Student Life** - Shows different parts of student life and activities at Coastal Carolina.
- **Sports** - Shows the different sports and athletic information.
- **Programs** - Shows different academic programs offered at Coastal Carolina.
- **Admissions** - Includes freshman requirements, transfer information, campus visits, financial aid, and an application link.
- **Alumni** - Provides information about staying connected, alumni events, giving back, and the Chanticleer community.
- **Contact** - Includes the university's address, phone number, admissions link, contact form, and map.
